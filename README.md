# Raspoznavatel_audio
Инструмент, который превращает вашу устную речь в текст прямо в браузере. Нажимаете «Записать», спокойно наговариваете что угодно — мысли, заметку, длинное сообщение, — а потом одной кнопкой копируете готовый текст и вставляете куда нужно: в переписку с нейросетью, в документ, в свою базу знаний.
